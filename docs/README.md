# Marsupial Mayhem™: the plan

These notes are the game's plan: everything decided so far, written so any Claude session can pick it up and keep building. **They contain story spoilers.**

The game is called **Marsupial Mayhem™** (chosen on 13 Nov 2026). The Great Pouch Tournament is the tournament in its story.

## Read in this order

| File | What's in it |
|---|---|
| `../CLAUDE.md` | Rules and working style for any Claude session on this project. Read automatically by Claude Code. |
| `DESIGN.md` | The game: pitch, story, modes, mechanics, worlds and levels, content guardrails |
| `ROSTER.md` | The 12 playable marsupials and 2 secret ones, with move sets, plus the full species list |
| `VILLAINS.md` | The quokka twist, the reptilians, the invasive-species villains, bosses, hazards and guests |
| `TECH_PLAN.md` | How to build it: reuse Sloth Slap's engine, architecture, budgets, testing, deployment |
| `BUILD_PLAN.md` | Milestones in order, each with "done when" checks. Start here when coding. |
| `DECISIONS.md` | What's decided, what's assumed, and the open questions for the owner |
| `../data/roster.json` | All 37 species from the planning sheet, machine-readable |
| `../data/villains.json` | Villains, guests and hazards, machine-readable |

The live planning sheet (private to the owner) is at https://claude.ai/artifact/2VDo2urAYgXyaWyEzfkeN9. `data/*.json` is a snapshot of it from 13 November 2026. The owner's later answers that day (name, story, weapons, blood) are in these docs but not in the sheet or the snapshot.
